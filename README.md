# Предметная область: Гостиница

## Описание области

Доменная область содерджить информацию о номерах, клиентах, и записях о бронировании.

### Сущности

- **Бронирование** — Дата заселения, кол-во дней, клиент, забронированная комната.
- **Клиент** — ФИО, Номер пасспорта, гражданство, дата рождения.
- **Номер** — Номер комнаты, этаж, тип комнаты, наличие балкона.
- **Тип Номера** — Площадь, кол-во кроватей, наличие ванны/душа, стоимость, категория.

## Технологии

- GitHub Actions
- .NET 10
- xUnit

## Unit-тесты

* Вывести информацию о всех клиентах, проживавших в номерах указанного типа, упорядочить по ФИО.
* Вывести информацию о номерах, находящихся в текущем бронировании.
* Вывести топ 5 наиболее часто бронируемых номеров.
* Для каждого номера вывести число бронирований.
* Вывести топ 5 клиентов по суммарной стоимости проживания.
